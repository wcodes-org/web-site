WCode - Website
==============

The Wordlist opens with all three filters inactive and shows the current words, including the **Greylist**. Select **Whitelist** to show only whitelist words, and select it again to return to the combined view. **Greylist** shows words under review, and **Blacklist** shows excluded words. Search groups results under **Whitelist**, **Greylist**, and **Blacklist**. Clearing search restores the view that was open before searching.

On `/wordlist`, **Group** switches between categories and one list per tab. **A–Z** and **Rank** select the sort order independently of grouping. With grouping on, each group is sorted independently. Rank order starts at 1, with unranked entries at the end. The same controls apply to search results.

Hover over or focus a ranked word to see its rank inline. Greylist tooltips show the reasons the word is on the Greylist.
